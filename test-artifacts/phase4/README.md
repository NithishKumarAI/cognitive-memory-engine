# Phase 4 browser evidence

Synthetic accounts and reflections only. Generated by `frontend/e2e/journeys.spec.ts` against the local production frontend and a new disposable PostgreSQL instance, with mocked embeddings, Gemini extraction and transcription. No physical microphone or real provider call was verified.

The responsive sweep visits Home, Capture Learning, Learning Paths, Next Actions, Insights, Memory, Assistant, Learning History, Search and Study Logs at 390, 768 and 1440 px, in both light and dark modes (60 route/viewport/theme combinations). Axe WCAG 2 A/AA and 2.1 AA scans run at 390 and 1440 px (40 scans). Overflow checks run at all three widths. Screenshots retain all ten routes at desktop plus Home at mobile/tablet in both themes. Manual visual inspection covered Home light desktop/dark mobile, Capture light desktop, Paths light desktop and populated Insights dark desktop. Automated scans do not establish complete accessibility or cross-browser support.
